# Midnight ID Studio

A one-file late-night TV ident generator built for Jake's nightly creative drop.

## What it is

**Midnight ID Studio** lets you invent a fake broadcast station and watch it come alive as an animated retro bumper.

You can:
- name the station, city, show, tagline, and airtime
- switch between multiple scene styles like Orbit Bloom, Velocity Tunnel, and Grid Horizon
- tap through neon/desert/casino-inspired palettes
- dial in bloom, static, scanlines, and screen warp
- toggle channel bugs, lower thirds, stars, and signal bars
- play a little synth stinger
- export the current frame as a PNG
- copy a generated voiceover script

## Why it's cool

It feels like designing the opening ident for a weird local station that only exists after midnight somewhere near Palm Springs.

It’s playful, polished, and surprisingly useful as a mood-board / branding toy.
